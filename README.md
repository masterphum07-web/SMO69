# ระบบเช็คชื่อสโมสรนักศึกษาปี 69
### วิทยาลัยเทคโนโลยีทางการแพทย์และสาธารณสุข กาญจนาภิเษก (วทก.)

## ✨ คุณสมบัติของระบบ

1. **หน้าแรกสาธารณะ (Public Dashboard & Leaderboard):**
   - ผู้ใช้งานทั่วไป (Guest) ดูได้ทันที ไม่ต้องล็อกอิน
   - แสดงสถานะการเช็คชื่อแบบเรียลไทม์ (Auto Sync ทุก 8 วินาที)
   - สรุปตัวเลข: **เข้าร่วม (มา)**, **มาสาย**, **ขอลา**, **ขาดกิจกรรม**, **ยังไม่เช็ค**
   - **Leaderboard ทั้งเทอม:** 5 อันดับแรกที่เข้าร่วมมากที่สุด และ 5 อันดับแรกที่ขาดมากที่สุด

2. **หน้าเช็คชื่อองค์ประชุม (Attendance Taking):**
   - สำหรับผู้เช็คชื่อ (Checker) และแอดมิน (Admin) โดยต้องล็อกอิน (ID + PIN)
   - เลือกองค์ประชุม หรือสร้างองค์ประชุมใหม่ กำหนดวันที่และสาขาเป้าหมายได้
   - กรองรายชื่อแยกตามสาขาวิชา พร้อม Badge สีประจำสาขาชัดเจน
   - ปุ่มเปลี่ยนสถานะ 4 สี:
     - 🟢 **มา (Present)** `#16A34A`
     - 🟡 **สาย (Late)** `#EAB308`
     - 🔵 **ลา (Excused)** `#3B82F6`
     - 🔴 **ขาด (Absent)** `#DC2626`
   - **บันทึกร่างอัตโนมัติ (Auto-Save Draft):** บันทึกทันทีเมื่อคลิกเปลี่ยนสถานะ
   - **ปุ่มยืนยันส่งผล (Submit):** ปิดรอบองค์ประชุม และสั่งคำนวณสรุปสถิติอัตโนมัติ

3. **แดชบอร์ดสรุปผลแอดมิน (Admin Dashboard):**
   - ตารางสถิติรายบุคคลพร้อมอัตราการเข้าร่วม (%)
   - ตัวกรองตามสาขาวิชา และช่วงเวลา
   - ดูประวัติองค์ประชุมย้อนหลังทั้งหมด
   - ปุ่มดาวน์โหลดสรุปผลเป็นไฟล์ Excel (CSV)

## 🛠️ ขั้นตอนการติดตั้งและเชื่อมต่อ Google Sheets (สำคัญมาก)

### ขั้นตอนที่ 1: สร้าง Google Sheets และใส่โค้ด Apps Script
1. ไปที่ [Google Sheets](https://sheets.new) เพื่อสร้างสเปรดชีตใหม่ (ตั้งชื่อเช่น `ระบบเช็คชื่อสโมสรนักศึกษาปี 69`)
2. ไปที่เมนูด้านบน คลิก **ส่วนขยาย (Extensions)** > **Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) ในโปรเจกต์นี้ไปวางแทนที่
4. กด **บันทึก (Save)** (ไอคอนแผ่นดิสก์)

### ขั้นตอนที่ 2: รันสร้างฐานข้อมูลครั้งแรก (1-Click Setup)
1. ในหน้าต่าง Apps Script ตรงแถบเลือกฟังก์ชันด้านบน ให้เลือกฟังก์ชัน **`setupInitialDatabase`**
2. คลิกปุ่ม **เรียกใช้ (Run)**
3. ระบบจะขอสิทธิ์การเข้าถึง (Authorization Required) ให้กด *ตรวจสอบสิทธิ์ (Review permissions)* > เลือกบัญชี Google ของคุณ > กด *ขั้นสูง (Advanced)* > กด *ไปที่... (ไม่ปลอดภัย / unsafe)* > กด *อนุญาต (Allow)*
4. รอจนขึ้นข้อความ Execution completed กลับไปดูที่ Google Sheets จะพบแท็บทั้ง 6 แท็บสร้างขึ้นมาพร้อมหัวตารางและข้อมูลจำลองเรียบร้อย:
   - `Branches`
   - `Students`
   - `Sessions`
   - `Attendance`
   - `Admins`
   - `Dashboard_Summary`

### ขั้นตอนที่ 3: Deploy เป็น Web App
1. ที่มุมขวาบนของ Apps Script คลิกปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้ใหม่ (New deployment)**
2. คลิกรูปฟันเฟือง ⚙️ ด้านซ้าย เลือกประเภท **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `SMO69 Attendance API v1`
   - **ดำเนินการในฐานะ (Execute as):** **ฉัน (Me)**
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** *(สำคัญมาก ต้องเลือก Anyone เพื่อให้เว็บเชื่อมต่อได้)*
4. คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy)**
5. คัดลอก **URL เว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec`

### ขั้นตอนที่ 4: นำ URL มาใส่ในหน้าเว็บ
1. เปิดหน้าเว็บ [https://masterphum07-web.github.io/SMO69/](https://masterphum07-web.github.io/SMO69/)
2. คลิกที่ปุ่มป้ายสถานะ **"โหมดจำลอง (Mock DB)"** ด้านขวาบน
3. นำ URL ที่คัดลอกมาวางในช่อง **Google Apps Script Web App URL**
4. ติ๊กยกเลิกตัวเลือก "ใช้โหมดข้อมูลจำลองในเครื่อง"
5. กด **🔌 ทดสอบการเชื่อมต่อ** แล้วกด **บันทึกการตั้งค่า**

## 👥 วิธีเพิ่มหรือแก้ไขรายชื่อนักศึกษาและสาขาจริงภายหลัง

เนื่องจากระบบถูกออกแบบมาให้ยึด Google Sheets เป็น **Single Source of Truth** คุณสามารถแก้ไขข้อมูลได้โดยตรงในชีตโดยไม่ต้องแก้โค้ด:

1. **เพิ่ม/แก้ไขสาขาวิชา:**
   - ไปที่แท็บ `Branches`
   - กรอก `branch_id`, `branch_name`, และโค้ดสี `color_hex` (เช่น `#2563EB`)
2. **เพิ่ม/นำเข้ารายชื่อนักศึกษา:**
   - ไปที่แท็บ `Students`
   - สามารถ Copy & Paste รายชื่อจากไฟล์ Excel เข้ามาในคอลัมน์ `student_id`, `full_name`, `branch_id` ได้ทันที
3. เมื่อมีนักศึกษาใหม่ แนะนำให้กดเรียกใช้ฟังก์ชัน `updateDashboardSummary` ใน Apps Script 1 ครั้ง หรือรอให้มีการส่งองค์ประชุมใหม่ ระบบจะคำนวณและดึงรายชื่อใหม่อัตโนมัติ
